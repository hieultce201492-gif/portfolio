BookStore – Online Bookstore Web Application
  • Công nghệ: ReactJS, Redux Toolkit, React Router DOM, Axios, Bootstrap 5, JSON Server.
  • Vai trò: Lập trình viên Frontend (Phụ trách Module Quản lý Sách phía Admin).
  • Nhiệm vụ cụ thể:
    • Phát triển giao diện và logic hiển thị danh sách sách quản trị (View Admin Books List) với các tính năng tìm kiếm (Search Books In Admin) và lọc theo danh mục (Filter Books By Category In Admin).
    • Xây dựng chức năng thêm mới sách (Create New Book) và cập nhật chi tiết sách (Update Book Details) với các biểu mẫu xử lý dữ liệu phức tạp.
    • Triển khai tính năng xóa thông tin sách (Delete Book) nhằm đảm bảo tính toàn vẹn dữ liệu trên hệ thống.
